# Media folder

Put your PDFs, deck exports, thumbnails and images here, organized one folder per item.

```
assets/media/
  workforce-planning/
    briefing.pdf
    thumb.jpg
  attrition-walkthrough/
    thumb.jpg
```

Then reference the path in `data/media.json` or `data/projects.json`.

Videos should go on YouTube/Vimeo (unlisted is fine) rather than in this folder —
see `docs/HOW-TO-ADD-MEDIA.md` for why.
